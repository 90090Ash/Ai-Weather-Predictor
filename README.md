# AI-Based Weather Temperature Prediction System 🌦️🤖

This project predicts temperature using Machine Learning (Random Forest) based on weather parameters such as humidity, wind speed, and atmospheric pressure.

## 🔗 Live Project Link
https://ai-weather-predictor.onrender.com/


## 🛠️ Technologies Used
- Python
- Flask
- Scikit-learn
- Random Forest Regressor
- HTML, CSS, JavaScript
- Render (Deployment)

## 📌 How It Works
1. User enters weather parameters
2. Flask API receives data
3. ML model predicts temperature
4. Compare Prediction of Model Used
5. Result displayed on UI
